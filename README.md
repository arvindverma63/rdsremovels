# RDS Removals & Storage - Modern Client Mockup

A modern, high-performance, responsive client website mockup for **RDS Removals & Storage** (UK).

## Features
- **Sleek Navigation**: Sticky responsive header with service mega-dropdown popover and click-to-call integration.
- **Cinematic Hero Carousel**: 4 synchronized service slides (Full Removals, Home Moves, Secure Storage, Commercial Relocations) with real-time animated progress bars, touch/swipe support, and Ken Burns cross-fade effects.
- **Fast Moving Estimate**: Embedded quote calculator with instant callback request form.
- **Interactive Moving Cost & Volume Estimator**: Dynamic property size, distance, packing, and storage sliders with instant price, cubic feet volume, and fleet van recommendations.
- **Services Showcase**: Detailed service cards with clean feature checklists.
- **Why Choose Us & Timeline**: 4-step moving process timeline and company guarantees (£50,000 goods in transit protection, 4.9★ rating).
- **Service Areas Covered**: Interactive town badges covering Dorset, Wiltshire, Somerset, and nationwide routes.
- **Customer Reviews Carousel**: High-converting client testimonials with star ratings.
- **Responsive & Mobile First**: Fully optimized across desktop, tablet, and mobile devices with zero horizontal overflow.

## Tech Stack
- HTML5 (Semantic, SEO-ready)
- Vanilla CSS3 (Custom design system, flexbox, grid, animations)
- Vanilla JavaScript (ES6+, zero external framework dependencies)
- Google Fonts (`Inter`, `Plus Jakarta Sans`)
